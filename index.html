Data connection & how the overlays work

One-time AWC setup: GitHub Pages cannot run a server, and AWC does not allow direct browser requests. Deploy the included worker.js as a Cloudflare Worker, then set DEFAULT_RELAY near the top of this HTML to its HTTPS URL before uploading to GitHub. You can also save the URL below for this browser. HRRR and the NWS discussion can load without the relay.

Method: NOAA HRRR only, via Open-Meteo; no AI model. A 0.6° sampling lattice (roughly 55–67 km) is interpolated into a smooth surface. This is a coarse visualization of model-derived point samples, not a native 3 km GRIB raster. The current nearest hourly forecast is used. Recent METAR minus model differences locally adjust temperature and wind components within about 100 km; observations older than 90 minutes are excluded. Wind paths illustrate an instantaneous field, not parcel trajectories or a forecast track. Terrain and small-scale wind effects are unresolved.

Refresh: observations every 5 minutes; discussion every 10 minutes; model every 60 minutes while open. Missing and stale data are labeled. Model fields expire after 90 minutes from their valid hour. Station timestamps are observation times. All displayed times use Arizona MST. The map uses an approximate Arizona boundary.
