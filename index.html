NOAA HRRR · experimental estimates

Cloud structure & potential icing

White map shading shows modeled cloud fraction. Select Icing composite to combine potential cloud/moisture overlap at 0 to −22°C across the sampled pressure levels. Click the amber map shading for estimated height bands in feet AGL. Below-model-ground samples are excluded.

Select an airport and use Load / refresh profile. Clicking a cloud-cover map loads a profile; clicking the icing composite opens its AGL textbox. Radar can obscure cloud shading.

Potential conditions are not a forecast of icing occurrence or severity. Supercooled liquid water is not measured here. No flag does not establish icing-free conditions. Use official aviation icing products and pilot reports for flight decisions.

How these estimates work

NOAA HRRR through Open-Meteo supplies cloud-cover bands and temperature, relative humidity and geopotential height. The map samples a 0.6° lattice, not the native 3 km grid. The profile uses 18 pressure samples from 1000 to 200 hPa. Contiguous relative humidity ≥85% is a heuristic moist-layer proxy; boundaries are interpolated between samples. Total cover ≥20% provides broad cloud support, not proof of cloud at a particular height. Thin layers can be missed.

Height above model terrain suggests low, middle or high cloud families. A deep moist layer with CAPE ≥1000 J/kg adds a convective candidate. These are candidate families, not visual cloud identifications. Model temperatures overlapping 0 to −22°C flag your requested screening range; no liquid-water or severity field is available. Surface METARs are not used to invent cloud tops or vertical temperatures.

Data sources, optional AWC connection & overlay method

Works without setup: METARs load from Iowa State University's Iowa Environmental Mesonet (IEM). The page labels that source honestly. If IEM is unavailable, the 12 watched stations are requested from NWS. Configure the optional JavaScript relay to prefer AWC; if the relay fails, the page falls back automatically.

Optional AWC setup: deploy the included worker.js as a Cloudflare Worker and set DEFAULT_RELAY in this HTML to its HTTPS origin for all visitors, or save it below for this browser. AWC blocks direct cross-origin browser requests. No Python, API key, or AI workflow is used by NDAWX.

Composite radar: NOAA NEXRAD base-reflectivity mosaic through IEM, the same kind of mosaic described by COD. This combines multiple radars horizontally; it is not a maximum-reflectivity-through-the-column product. Tiles use XYZ row coordinates and are pinned to the published scan timestamp. Enabled on load, checked every 5 minutes, and hidden when older than 20 minutes. No API key or relay is required. Missing coverage and no echoes can both appear transparent. The matching NEXRAD dBZ legend is shown below the map.

Gusts: station dots, popups and the watch list show reported METAR gusts in knots. “Not reported” means the report has no gust group; it does not mean zero. The selectable HRRR gust shading and map-value popup are model-only estimates, separate from observed gusts. Daily maximum gusts are never substituted for current gusts.

Wind: animated particles follow the estimated instantaneous wind field. The speed slider exaggerates movement for visibility; it is not elapsed meteorological time. Pause/play is available, animation stops in hidden tabs, and reduced-motion preferences pause it initially.

Model: NOAA HRRR via Open-Meteo, sampled on a 0.6° grid (roughly 55–67 km), with bilinear interpolation. This is not a native 3 km GRIB raster. Recent METAR minus model differences adjust temperature and sustained wind components locally within 100 km; reports older than 90 minutes are excluded. Gusts are not used to drive sustained-wind animation. No field is shown without current HRRR data.

Airspaces: live FAA GIS boundaries in the Arizona region include Class B/C/D (blue / pink / dashed blue), optional Class E (dashed purple), special-use areas (amber/orange), and special-rule areas including Grand Canyon (teal). Click a boundary for its name, floor and ceiling. Neighboring areas may extend outside Arizona. Layers are plan views at all altitudes, not a sectional chart, clearance, activation feed or complete TFR/NOTAM service. Check FAA SUA and current charts for operational use.

Refresh: METARs and radar every 5 minutes, Phoenix discussion every 10 minutes, HRRR hourly, airspace daily while open. Source failures are shown independently; previous observations retain their original timestamps. All times are Arizona MST. HRRR fields expire 90 minutes from their valid hour.
